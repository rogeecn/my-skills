# 新增剧目剧照索引模板

> 各剧目剧照来源参考——统一格式

## 通用搜索方式

每个剧目的剧照可通过以下方式获取:

1. **百度图片搜索**: "豫剧{剧名} 剧照" — 最直接的剧照来源
2. **B站视频截取**: 搜索"豫剧{剧名} 全场"，下载视频截取关键场景
3. **抖音短视频**: 搜索"豫剧{剧名}"，截取剧照
4. **河南戏曲网**: henanxiqu.cn — 有部分剧目剧照
5. **戏曲文化网**: xiquwenhua.net — 有部分剧目剧照和文章配图
