# 豫剧公众号内容创作

## 状态数据分离规则

**SKILL 是只读技能资产，不含状态信息。** 所有带状态的数据必须存放在 workspace 级别隐藏目录中：

| 类型 | 路径 | 说明 |
|------|------|------|
| 只读技能资产 | `yuju_豫剧/references/` | 蒸馏参考数据，只读不写 |
| 只读技能资产 | `yuju_豫剧/SKILL.md` | 技能流程定义，只读 |
| 运行时状态 | `workspace/.yuju_豫剧/output/` | 创作输出，读写 |
| 运行时状态 | `workspace/.yuju_豫剧/content_history.json` | 近30篇创作记录，读写 |
| 环境变量 | `workspace/.env` | .env仅允许在此文件读写，禁止其他位置 |

**关键约束：** 本SKILL目录下的所有文件都是只读资产，不得写入任何运行时状态。`output/` 和 `content_history.json` 等带状态数据只能存在于 `workspace/.yuju_豫剧/` 中。首次运行时如果 `workspace/.yuju_豫剧/` 目录不存在，需要创建它。

## 概述

**选题 → 创作 → 去重审核 → 风格增强 → 自检 → 保存** 六阶段技能，共10个步骤。支持单篇和系列连载两种输出模式。所有推导基于交叉矩阵和references目录下的数据文件，创作完成后自动记录到近30篇章历史中防止同质化。风格增强阶段会注入戏味感写作手法（戏曲口语转场、板式节奏断裂、曲牌知识随手掏等），自检阶段用四层质检体系确保成品无AI味。

阶段与步骤对应关系：
- 第一阶段（选题）：步骤1确定上下文、步骤2生成选题、步骤3去重审核、步骤4呈现选择
- 第二阶段（创作）：步骤5叙事基调、步骤6推导文章、步骤7风格增强、步骤8四层自检
- 第三阶段（保存）：步骤9保存文件
- 第四阶段（收尾）：步骤10提供选项

## 第一阶段：选题

### 步骤1：确定上下文

选题前，先确定4个上下文因素：

1. **当前时令** — 读取 `references/豫剧全年节庆纪念日日历.yaml`，定位当前周的节庆纪念日
2. **生命事件** — 询问用户或受众是否正在经历某个生命事件（回乡看戏、第一次现场看戏、名家逝世、学唱豫剧等），读取 `references/豫剧生命事件维度.yaml`。**生命事件优先级高于时令**
3. **目标受众** — 询问面向哪类受众（老戏迷/文化爱好者/年轻传承者/河南老乡/传统艺术好奇者），或默认五类轮转各产一条
4. **品类偏好** — 询问感兴趣的品类，或读取 `references/豫剧受众画像矩阵.yaml` 按关注度自动分配

### 步骤2：生成3-5个选题

选题推导公式扩展为三种：

- **基础选题**: `A_子品类 × B_受众类型 × C_时令周期` — 读取 `references/豫剧内容品类交叉矩阵.yaml`
- **事件选题**: `A_子品类 × B_受众类型 × C2_生命事件` — 读取 `references/豫剧生命事件维度.yaml`
- **交叉选题**: `A1_子品类 × A2_子品类 × B_受众类型 × (C_时令 | C2_生命事件)` — 读取 `references/豫剧内容品类交叉矩阵.yaml` 的跨品类交叉组合

**每批3-5个选题中必须包含：至少1个跨品类交叉选题 + 至少1个与时令或生命事件绑定的选题。**

每个选题必须包含以下字段：

| 字段 | 数据来源 |
|------|----------|
| 选题名称 | 交叉推导结果（基础/事件/交叉） |
| 推荐理由 | 引用受众画像矩阵的切入角度，说明该组合为何有效 |
| 目标受众 | B_受众类型及其核心心态描述 |
| 时令/事件关联 | C_时令的选题方向，或C2_生命事件的核心场景 |
| 长尾关键词 | 从 `references/豫剧长尾关键词总表.yaml` 取该子品类×受众的2-3个关键词 |
| 品类关注度 | 从 `references/豫剧受众画像矩阵.yaml` 读取关注度等级 |
| 选题类型标注 | 标注"基础/事件/交叉"，方便后续叙事基调选择 |

**多样性规则：** 3-5个选题必须覆盖不同品类和不同受众，禁止全部来自同一品类或同一受众。

### 步骤3：去重审核（Guarder）

选题生成后、呈现给用户前，**必须执行去重审核**：

1. 读取 `workspace/.yuju_豫剧/content_history.json`
2. 将每个候选选题与近30篇章记录对比，检查以下维度是否重复：
   - **子品类重复** — 近30篇中同一A_子品类出现≥5次，该子品类降权
   - **受众重复** — 近30篇中同一B_受众类型出现≥10次（占比超33%），该受众降权
   - **选题核心主题重复** — 近30篇中有相同核心主题（如"花木兰"出现3次），该主题降权
   - **叙事基调重复** — 近30篇中焦虑型>60%，本轮优先赋能型和温暖型
   - **标题公式重复** — 近30篇中同一标题公式出现≥3次降权；≥5次禁用
3. 如发现重复风险，替换重复选题为低频品类/受众/基调的新选题
4. 向用户说明去重调整结果

### 步骤4：呈现选题供用户选择

使用 `question` 工具呈现。

**系列触发检查：** 如果用户连续3次选择同品类/同受众选题，或用户提到"做几天"、"系列"、"一周内容"，建议切换到系列模式（读取 `references/豫剧内容系列模板.yaml`）。

## 第二阶段：创作

### 步骤5：选择叙事基调

根据选题类型和受众选择基调，读取 `references/豫剧正向叙事模板.yaml` 中的选择规则：

| 条件 | 基调要求 |
|------|----------|
| 年轻传承者选题 | 一律使用燃型或赋能型 |
| 老戏迷选题 | 可焦虑开头但中段必须转为赋能叙事 |
| 文化爱好者选题 | 温暖型和好奇型各占一半 |
| 河南老乡选题 | 共鸣型为主，偶尔温暖型 |
| 传统艺术好奇者选题 | 好奇型和权威型各占一半 |
| 跨品类交叉选题 | 一律使用赋能型叙事 |
| 名家逝世事件 | 一律温暖/共鸣，禁止焦虑 |
| 抗战类事件 | 一律家国/燃型，禁止焦虑 |
| 非遗纪念日 | 温暖开头+赋能结尾 |

### 步骤6：推导文章各部分

**标题推导：** `选题 × (D_标题公式 | D2_赋能公式) × (E_情感触发 | E2_赋能触发) → 5+标题变体`
- 从 `references/豫剧标题公式库.yaml` 和 `references/豫剧正向叙事模板.yaml` 中选取兼容公式
- 必须检查适用品类和适用受众约束
- 共生成5-8个标题变体

**大纲推导：** `选题 × B_受众类型 × 叙事基调 → 大纲框架`
- 根据受众和基调选择对应大纲模板

**交叉选题正文篇幅分配规则：** 当选题类型为"交叉"时，大纲和正文中两品类必须各占至少30%篇幅。

**开头推导：** `选题 × 情感触发 × B_受众类型 → 开头段落`

**平台适配：** 读取 `references/豫剧平台适配指南.yaml`

### 步骤7：风格增强（戏味感注入）

初稿完成后，读取 `references/豫剧写作风格库.md`，对正文草稿进行风格增强。

**必须增强的手法（每篇至少使用5种）：**

- **戏迷口语转场**：把"接下来让我们讨论"换成"说到这个戏""再聊聊这块""换个角儿看看"
- **板式节奏断裂**：用戏曲板式类比写作节奏，在情绪高点用极短的句子独立成段。全文至少出现3处
- **曲牌知识随手掏**：把"下面我来科普一下xxx"改成"聊着聊着想起来一个东西，这玩意叫xxx"
- **戏迷自嘲与真实暴露**：至少一处承认不足或自嘲。"说实话我对那个板式也不全懂""我这个半吊子戏迷"
- **句式故意打破**：重复强调、中途模糊、省略主语
- **扣主线句**：偏离主线段落后面必须有一句话拉回来
- **疑问句刹车**：用疑问句让读者停一秒
- **文化升维**：从具体事件连接到更大的戏曲/文化/历史参照物
- **人物画像法**：从一个数据点想象背后那个具体的人的完整人生
- **回环呼应**：开头或中间留一个意象/句子/小钩子，结尾callback回来
- **谦逊铺垫**：给出观点前先用自谦降低防御心
- **读者直呼**：在关键节点直接跟读者对话
- **情绪标点**：用"。。。"表示感慨/拖长

**绝对禁区（必须避免）：**

1. **套话**：禁用"首先...其次...最后"、"综上所述"、"值得注意的是"、"不难发现"、"让我们来看看"、"接下来让我们"
2. **过度结构化**：不用bullet point罗列观点，不大量加粗
3. **标点禁令**：不使用冒号"："（用逗号代替），不使用破折号"——"（用逗号或句号），不使用任何双引号（用「」或不加引号）
4. **高频踩雷词**：禁用"说白了""意味着什么""这意味着""本质上""换句话说""不可否认"
5. **假设性例子**：不用编造场景
6. **空泛工具名**：不说"某个戏曲平台"，说具体名字
7. **教科书开头**：禁止空话开头，永远从具体的戏/唱段/名家故事切入
8. **伪专业**：不堆砌术语吓退读者，术语必须配大白话解释

### 步骤8：四层自检体系

逐层检查，每层输出明确的检查结果。使用以下模板：

```
## L1 硬性规则检查
- 禁用词扫描：[命中数/具体词] → 目标零命中
- 禁用标点扫描（冒号/破折号/双引号）：[命中数/具体位置] → 目标零命中
- 结构性套话扫描（首先其次最后/综上所述等）：[命中数] → 目标零命中
- 空泛名扫描（某个平台/某种说法）：[命中数] → 目标零命中
- L1结论：✅通过 / ❌未通过（需修改的具体位置）

## L2 风格一致性检查
- 开头类型：[教科书式空话/具体事物切入] → 必须为后者
- 节奏与结构：[bullet point罗列/自然叙事流] → 必须为后者
- 口语化程度：[书面语堆砌/戏迷口语转场≥2处] → 必须为后者
- 标点二次确认（冒号/破折号/双引号有无遗漏）：[结果]
- L2结论：✅通过 / ❌未通过

## L3 内容质量检查
- 观点支撑：每个观点是否有具体戏/唱段/名家/数据支撑 → [结果]
- 知识输出方式：[教科书式科普/曲牌知识随手掏] → 必须为后者
- 文化升维：至少1处从具体事件连接到更大参照物 → [结果]
- 对立面与同理心：是否考虑不同立场 → [结果]
- 选题类型专项（交叉选题篇幅均衡/年轻传承者赋能基调等）：[结果]
- L3结论：✅通过 / ❌未通过

## L4 戏味感终审
- 温度感：读起来像"一个懂戏的人在跟我聊"还是"AI在输出知识" → [结果]
- 独特性：有没有至少1个只有这篇才有的观点或角度 → [结果]
- 姿态检查：有无自嘲/谦逊铺垫至少1处 → [结果]
- 心流检查：从开头到结尾能否一口气读完不停顿 → [结果]
- 戏味感手法使用数：[数量/具体手法名] → 必须≥5
- L4结论：✅通过 / ❌未通过
```

任何一层未通过，必须修改对应问题后重新检查该层，直到全部通过。

3. 保存 `plan.md` 和 `article.md`
4. 追加创作记录到 `workspace/.yuju_豫剧/content_history.json`
5. 裁剪历史记录至30条以内

### 步骤10：完成后提供选项

- 继续选题（再来一批）
- 修改当前文章内容
- 批量生成（切换到系列模式）
- 查看近30篇创作记录

## 约束条件

- **排除项：** 禁止涉及政治敏感内容
- **兼容性：** 标题公式和情感触发必须与品类和受众兼容
- **多样性：** 每批选题必须覆盖不同品类和受众，至少1个交叉选题
- **时令/事件优先：** 有生命事件时事件优先，无事件时时令优先
- **去重审核：** 每批选题必须经过Guarder去重审核
- **交叉篇幅：** 交叉选题正文中两品类各占至少30%篇幅
- **叙事基调伦理：** 年轻传承者禁止焦虑，交叉选题一律赋能型
- **风格增强必做：** 步骤7风格增强必须执行，每篇至少5种戏味感手法
- **四层自检必做：** 步骤8四层自检必须执行
- **标点禁令：** 全文禁止冒号、破折号、双引号
- **禁用词零容忍：** "说白了""意味着什么"等一律禁用
