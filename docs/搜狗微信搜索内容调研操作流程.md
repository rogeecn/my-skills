# 搜狗微信搜索内容调研操作流程

> 仅使用 agent-browser（browser-harness）工具进行搜狗微信搜索的内容调研
> 版本: v1.0 | 日期: 2026-05-14
> 适用: 任何垂直内容赛道的公众号竞品数据采集

---

## 核心原则

1. **仅用 agent-browser**，不使用 firecrawl 或其他抓取工具
2. **多页数据最少翻3页**，确保数据量足够
3. **打开的链接有图片懒加载**，需滚动触发后再采集
4. **用完立即关闭 tab**，防止 tab 爆炸导致浏览器崩溃
5. **逐轮搜索逐轮记录**，每轮搜索完成后立即将数据写入调研记录文件

---

## 全流程总览

```
准备 → 搜索轮次循环 → 关闭浏览器 → 蒸馏记录为竞品维度文件
```

搜索轮次循环内部：
```
打开搜狗 → 输入关键词 → 等待加载 → 采集第1页数据 → 翻页采集第2-3页 → 关闭tab → 记录数据 → 下一轮关键词
```

## 第一阶段：准备

### 步骤1：确定搜索关键词清单

在打开浏览器之前，先确定本轮调研需要搜索的所有关键词。参考《调研流程方法论》中"步骤4：竞品数据专项采集"的维度规划：

**必搜关键词（6类）：**

| 类别 | 关键词模板 | 采集目标 |
|------|-----------|---------|
| 赛道总览 | `"{赛道名}"` | 总文章数量 + 竞品账号全貌 |
| 核心品类 | `"{赛道名} {品类关键词}"` | 各品类文章量分布 |
| 爆款传播 | `"{赛道名} 爆款 热门"` | 爆款标题模式 |
| 热门话题 | `"{赛道名} {热门具体话题}"` | 特定话题深度数据 |
| 地域/人物 | `"{赛道名} {地域/人物关键词}"` | 竞争空白发现 |
| 新媒体 | `"{赛道名} 短视频 抖音 B站"` | 跨平台传播数据 |

**关键词数量：** 专业赛道8-12轮，生活赛道5-8轮

## 第二阶段：搜索轮次循环

每一轮搜索都是一个完整的 "打开→搜索→采集→翻页→记录→关闭" 循环。

### 步骤3：打开搜狗微信搜索

```bash
agent-browser open https://weixin.sogou.com
agent-browser wait --load networkidle
agent-browser snapshot -i
```

确认搜索框元素可见。通常搜索框是 `input type="text"` 元素，记下其 ref（如 `@e3`）。

### 步骤4：输入关键词并搜索

```bash
agent-browser fill {搜索框ref} "{关键词}"
agent-browser press Enter
agent-browser wait --load networkidle
agent-browser snapshot -i
```

### 步骤5：采集第1页数据

搜索结果页加载后，采集以下数据：

**5a. 记录总结果数**

搜狗微信搜索页面顶部通常会显示"为您找到 XXX 条相关结果"。使用以下方法获取：

```bash
agent-browser get text body
```

从全文中提取总结果数。或更精准地用 snapshot 定位显示数量的元素：

```bash
agent-browser snapshot -i
# 找到显示结果数的元素，如 @e1 [text] "为您找到 7921 条相关结果"
agent-browser get text {数量元素ref}
```

**5b. 逐条采集搜索结果**

搜狗微信搜索结果页的每条结果通常包含：
- 文章标题（链接）
- 公众号名称
- 发布时间
- 摘要片段

采集方法有两种：

**方法A：snapshot + eval批量提取（推荐，速度快）**

```bash
agent-browser snapshot -i --json
# 从JSON中提取所有搜索结果的结构化数据

# 或使用eval直接提取：
cat <<'EOF' | agent-browser eval --stdin
const results = document.querySelectorAll('.news-box .news-list li');
Array.from(results).map(r => ({
  title: r.querySelector('.txt-box h3 a')?.innerText?.trim() || '',
  account: r.querySelector('.txt-box .account')?.innerText?.trim() || '',
  time: r.querySelector('.txt-box .s-p')?.innerText?.trim() || '',
  url: r.querySelector('.txt-box h3 a')?.href || '',
  summary: r.querySelector('.txt-box p')?.innerText?.trim() || ''
}));
EOF
```

注意：搜狗微信搜索的CSS选择器可能随版本变化，如果上面选择器不匹配，先用 `snapshot -i` 观察页面结构，再调整选择器。

**方法B：逐条snapshot提取（慢但可靠）**

```bash
agent-browser snapshot -i
# 逐个记下每条结果的 ref
agent-browser get text {标题ref}
agent-browser get attr {标题ref} href
agent-browser get text {公众号ref}
agent-browser get text {时间ref}
```

### 步骤6：翻页采集第2-3页（最少3页）

**6a. 点击"下一页"**

```bash
agent-browser snapshot -i
# 找到"下一页"按钮的ref
agent-browser click {下一页按钮ref}
agent-browser wait --load networkidle
```

如果搜狗使用页码链接而非"下一页"按钮：

```bash
agent-browser find text "2" click
agent-browser wait --load networkidle
```

**6b. 采集第2页数据**

重复步骤5b的采集方法。

**6c. 继续翻到第3页**

```bash
agent-browser snapshot -i
agent-browser click {下一页按钮ref}
# 或 agent-browser find text "3" click
agent-browser wait --load networkidle
```

**6d. 采集第3页数据**

重复步骤5b的采集方法。

**翻页完成后的关键操作：**

翻到第3页并采集完数据后，**立即将本轮所有数据写入调研记录文件**（步骤2创建的文件）。不要等到所有轮次结束后再统一记录，防止中途出错丢失数据。

### 步骤7：深度阅读——打开有价值文章（可选）

如果某条搜索结果的标题看起来包含关键数据（如深度解读、名家传记、爆款分析等），可以打开该文章阅读详细内容。

**7a. 在新tab中打开文章链接**

```bash
agent-browser snapshot -i
# 找到目标文章标题链接的ref
agent-browser click {文章链接ref} --new-tab
agent-browser wait --load networkidle
```

或使用 `tab new` 直接打开URL：

```bash
agent-browser tab new {文章URL}
agent-browser wait --load networkidle
```

**7b. 处理图片懒加载**

微信公众号文章几乎都有图片懒加载。必须滚动页面触发图片加载，否则采集到的内容会不完整：

```bash
# 分段滚动，触发所有懒加载图片
for i in {1..10}; do
    agent-browser scroll down 800
    agent-browser wait 500
done

# 等待所有图片加载完成
agent-browser wait --load networkidle

# 采集全文内容
agent-browser get text body
```

**滚动次数计算：** 一篇典型公众号文章约3000-5000字，页面高度约5000-8000px。每次滚动800px，滚动8-10次基本覆盖全文。长文章（如百科级别的深度文章）可能需要15-20次滚动。

**7c. 采集文章数据**

```bash
# 获取文章标题
agent-browser get text body | head -1

# 获取完整正文
agent-browser get text body > {输出文件路径}

# 或更精准地获取正文区域
agent-browser snapshot -i
agent-browser get text {正文区域ref}
```

**7d. 关闭文章tab（防止tab爆炸）**

**这是最关键的操作。读完文章后必须立即关闭该tab：**

```bash
agent-browser tab
# 查看当前tab列表，找到文章tab的编号
agent-browser tab close {文章tab编号}

# 切回搜狗搜索结果页
agent-browser tab {搜索结果页tab编号}
```

或者更简单的做法：关闭所有非搜索页的tab后重新回到搜索页：

```bash
agent-browser tab close {文章tab编号}
agent-browser snapshot -i  # 确认回到搜索结果页
```

**绝对禁止：** 打开多篇文章后不关闭，导致tab数量持续增长。每读完一篇必须关闭，tab总数控制在2个以内（1个搜狗搜索页 + 最多1个正在阅读的文章页）。

### 步骤8：准备下一轮搜索

回到搜狗搜索结果页后，有两种方式进入下一轮：

**方式A：在当前搜索页清空重新搜索（推荐，节省时间）**

```bash
agent-browser snapshot -i
# 找到搜索框ref
agent-browser fill {搜索框ref} "{新关键词}"
agent-browser press Enter
agent-browser wait --load networkidle
```

注意：`fill` 命令会先清空输入框再填入新内容，所以直接填新关键词即可。

**方式B：重新打开搜狗首页（适合页面状态混乱时）**

```bash
agent-browser open https://weixin.sogou.com
agent-browser wait --load networkidle
agent-browser snapshot -i
agent-browser fill {搜索框ref} "{新关键词}"
agent-browser press Enter
agent-browser wait --load networkidle
```

### 步骤9：循环所有关键词

对关键词清单中的每个关键词，重复步骤4-8的完整循环：

```
关键词1: 搜索 → 采集3页 → 深度阅读(可选) → 关闭tab → 记录数据
关键词2: 搜索 → 采集3页 → 深度阅读(可选) → 关闭tab → 记录数据
关键词3: ...
...
关键词N: ...
```

每轮结束后立即写入调研记录文件。

## 第三阶段：结束与清理

### 步骤10：关闭浏览器

所有关键词搜索完成后，关闭浏览器：

```bash
agent-browser close
```

如果还有未关闭的tab：

```bash
agent-browser close --all
```

**务必执行此步骤。** 长时间不关闭浏览器会占用系统资源，且下次打开可能使用旧的tab状态。

### 步骤11：整理原始记录

检查 `搜狗微信搜索原始记录.md` 文件的完整性：

- 每轮搜索的关键词、总结果数、3页数据是否齐全
- 深度阅读的文章内容是否已完整记录
- 是否有搜索失败或翻页异常的轮次需要补搜

## 第四阶段：蒸馏为竞品维度文件

原始记录完成后，按以下维度蒸馏为结构化YAML文件。这是调研的最终产出，参照《调研流程方法论》步骤6的维度10-11。

### 产出1：竞品账号分析

**文件：** `{赛道名}竞品账号分析.yaml`

**蒸馏方法：** 从原始记录中提取所有出现的公众号账号，按出现频次和内容特征分类：

```yaml
竞品账号:
  - 名称: "{公众号名}"
    定位: "{从标题推断的内容定位}"
    内容模式: "{合集盘点/深度解读/人物故事/...}"
    受众: "{从内容推断的目标受众}"
    出现频次: {在搜索结果中出现的次数}
    代表标题:
      - "{3-5个典型标题}"

差异化定位建议:
  - "{基于竞品空白发现的定位方向}"
```

### 产出2：标题示例集

**文件：** `{赛道名}公众号标题示例集.yaml`（或纳入竞品账号分析.yaml）

**蒸馏方法：** 从原始记录中提取所有标题，按类型分类并分析竞争空白：

```yaml
标题类型分布:
  合集盘点型:
    占比: "{百分比}"
    示例: ["{标题1}", "{标题2}"]
  剧目推荐型:
    占比: "{百分比}"
    示例: ["{标题1}", "{标题2}"]
  # ... 其他类型

竞争空白:
  - 类型: "{未被使用的标题类型}"
    描述: "{说明为什么这个类型有空间}"
```

### 产出3：传播量化数据

**文件：** `{赛道名}爆款分析与传播数据.yaml`

**蒸馏方法：** 从原始记录中提取所有量化数据：

```yaml
搜索数据:
  总搜索结果数: {总条数}
  各关键词结果数:
    {关键词1}: {条数}
    {关键词2}: {条数}

传播数据:
  抖音播放量: "{如有}"
  B站相关: "{如有}"
  # ... 其他平台数据
```

## 实操注意事项

### 搜狗微信搜索的反爬应对

搜狗微信搜索有反爬机制，可能出现以下情况：

| 情况 | 表现 | 应对方法 |
|------|------|---------|
| 验证码拦截 | 页面显示验证码 | 等待几分钟再搜索，或换关键词顺序避免密集搜索 |
| 结果数显示为0 | 搜索无结果 | 检查关键词是否正确，尝试换用更短或更宽的关键词 |
| 页面加载缓慢 | 长时间白屏 | 增加 `wait --load networkidle` 的等待时间 |
| 搜索框找不到 | snapshot没有搜索框 | 搜狗可能改版，用 `find text "搜索"` 或 `find placeholder` 定位 |

### 搜索关键词技巧

| 技巧 | 说明 | 示例 |
|------|------|------|
| 从宽到窄 | 先搜宽泛词再搜精确词 | 先搜"豫剧"，再搜"豫剧 常香玉 花木兰" |
| 避免过短 | 1-2个字的关键词结果太多且不精准 | "豫" → "豫剧" |
| 避免过长 | 10+字的关键词可能搜不到结果 | "豫剧常香玉花木兰穆桂英挂帅经典名段合集" → 拆分为2-3个关键词分别搜索 |
| 加平台词 | 加"公众号""微信"扩大搜索范围 | "豫剧 公众号" |
| 加热门词 | 加"爆款""热门""10万+"找传播数据 | "豫剧 爆款" |

### 图片懒加载的完整处理流程

微信公众号文章的图片懒加载是内容采集的最大障碍。完整流程：

```
1. 打开文章页面
2. 等待 networkidle（页面骨架加载完成）
3. 循环滚动（每次800px，间隔500ms）
4. 滚动8-10次覆盖典型文章长度
5. 再次等待 networkidle（图片加载完成）
6. 采集全文内容
7. 关闭tab
```

**验证图片是否全部加载的方法：**

```bash
cat <<'EOF' | agent-browser eval --stdin
const images = document.querySelectorAll('img');
const loaded = Array.from(images).filter(img => img.complete && img.naturalHeight > 0);
const total = images.length;
`${loaded.length}/${total} images loaded`;
EOF
```

如果 loaded/total 不等于 total/total，继续滚动并等待。

### Tab管理铁律

| 规则 | 说明 |
|------|------|
| 同时最多2个tab | 1个搜狗搜索页 + 1个正在阅读的文章 |
| 读完立即关闭 | 每读完一篇文章，立即 `tab close` |
| 搜索页是常驻tab | 搜狗搜索页tab保持不关，所有翻页搜索在同一个tab内完成 |
| 每轮搜索结束检查 | `agent-browser tab` 查看tab数量，超过2个就有问题 |
| 所有搜索完成后关闭浏览器 | `agent-browser close` |

## 完整操作示例脚本

以下是一个3轮搜索的完整示例，展示每一步的具体命令：

```bash
# ====== 第1轮: 搜索"{赛道名}" ======

# 打开搜狗
agent-browser open https://weixin.sogou.com
agent-browser wait --load networkidle
agent-browser snapshot -i

# 搜索关键词
agent-browser fill @e1 "豫剧"
agent-browser press Enter
agent-browser wait --load networkidle

# 采集第1页
agent-browser snapshot -i
# 记录总结果数
# 记录每条结果

# 翻到第2页
agent-browser find text "2" click
agent-browser wait --load networkidle
# 采集第2页数据

# 翻到第3页
agent-browser find text "3" click
agent-browser wait --load networkidle
# 采集第3页数据

# 写入调研记录文件（立即执行，不等后续轮次）

# ====== 第2轮: 搜索"{赛道名} 常香玉" ======

# 清空搜索框重新搜索
agent-browser snapshot -i
agent-browser fill @e1 "豫剧 常香玉"
agent-browser press Enter
agent-browser wait --load networkidle

# 采集3页（重复上面的翻页采集流程）
# ...

# ====== 第3轮: 搜索"{赛道名} 爆款" 并深度阅读一篇 ======

agent-browser fill @e1 "豫剧 爆款"
agent-browser press Enter
agent-browser wait --load networkidle
# 采集3页数据

# 发现一篇有价值的深度文章，打开阅读
agent-browser snapshot -i
agent-browser click @e10 --new-tab  # 在新tab打开
agent-browser wait --load networkidle

# 处理图片懒加载
for i in {1..10}; do
    agent-browser scroll down 800
    agent-browser wait 500
done
agent-browser wait --load networkidle

# 采集文章全文
agent-browser get text body > yuju_豫剧/原调研资产/爆款文章1.md

# 关闭文章tab（关键操作！）
agent-browser tab
agent-browser tab close 2

# 切回搜索页继续
agent-browser tab 1
agent-browser snapshot -i

# ====== 所有搜索完成，关闭浏览器 ======

agent-browser close
```

## 常见问题

| 问题 | 原因 | 解决方法 |
|------|------|---------|
| 搜索结果为空 | 关键词过窄或搜狗反爬 | 换更宽的关键词，或等待几分钟 |
| 翻页后页面没变化 | 搜狗可能用JS翻页 | `wait --load networkidle` 后再 `snapshot -i` |
| 文章内容不完整 | 图片懒加载未触发 | 增加滚动次数和等待时间 |
| 文章打开后是验证码 | 搜狗拦截访问 | 等待后重试，或跳过该文章 |
| Tab数量持续增长 | 未关闭阅读过的文章tab | 严格执行读完即 `tab close` |
