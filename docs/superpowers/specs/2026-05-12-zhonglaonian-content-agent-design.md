# 中老年内容创作Agent — 选题与素材库设计文档

## 项目概述

构建面向45-80岁中老年群体的内容选题Agent，产出全年创作素材库（约1095条），支持每天3条内容分别覆盖3个年龄段。

## 需求确认

| 维度 | 确认结果 |
|------|----------|
| 目标群体 | 45-80岁，分3档：45-60 / 55-70 / 65-80 |
| 日产量 | 3条/天（每年龄段1条），年产量约1095条 |
| 平台 | 视频号、今日头条/小红书、微信公众号、抖音/快手 |
| 内容品类 | 全品类覆盖 + 长尾关键词深度挖掘 |
| 调性 | 百花齐放，不限风格 |
| 产出结构 | 分类素材库 + 关键词矩阵 |
| 排除项 | 政治、新闻等需资质内容 |
| 每条素材深度 | 选题 + 大纲框架 + 标题备选(5+) + 开头示例 |

## 调研方案：混合驱动（品类框架 + 爆款验证 + 节令日历）

### 内容品类框架（7大一级品类）

| 一级品类 | 二级子品类 |
|----------|-----------|
| 健康养生 | 中医养生、常见病防治、运动健身、睡眠改善、饮食调理、心理健康、季节养生 |
| 家庭关系 | 婆媳相处、夫妻关系、子女沟通、隔代教育、空巢心态、家庭矛盾化解 |
| 生活方式 | 退休适应、闲适生活、回忆怀旧、人生感悟、日常闲聊、仪式感生活 |
| 实用技能 | 智能手机使用、防诈骗指南、线上购物、出行攻略、政务办理、新技能学习 |
| 兴趣娱乐 | 旅游出行、美食烹饪、手工园艺、棋牌文化、广场舞/运动、摄影书画 |
| 财富理财 | 养老金规划、退休理财、房产安排、保险选择、消费观、遗产规划 |
| 社交情感 | 老年交友、孤独感应对、婚恋再出发、社区融入、代际社交、情感表达 |

### 关键词矩阵三层结构

一级品类 → 二级子品类 → 长尾关键词群（每个子品类10-20个长尾词）

交叉维度：
- × 年龄段（45-60 / 55-70 / 65-80）
- × 平台适配（短视频 vs 图文 vs 混合）
- × 节令时序（全年52周，绑定节气/节日/时令）

### 每条素材标准格式

```yaml
选题ID: <CATEGORY-SUBCATEGORY-NNN>
一级品类: <name>
二级子品类: <name>
长尾关键词: [<list of 10-20 keywords>]
目标年龄段: <45-60 / 55-70 / 65-80>
节令标签: [<seasonal tags>]
平台适配建议: [<platform-specific format hints>]

标题备选(5+):
  - <title 1>
  - <title 2>
  - <title 3>
  - <title 4>
  - <title 5>

大纲框架:
  开头: <hook type>
  主体: <3-5 key points>
  结尾: <call-to-action>

开头示例:
  <2-3 sentences opening paragraph>
```

### 多Agent调研执行架构（7个并行Agent）

| Agent | 职责 | 产出 |
|-------|------|------|
| A1-品类框架 | 逐个深挖7大品类的子品类和长尾关键词 | 品类×子品类×长尾词清单 + 原始关键词数据 |
| A2-爆款数据 | 搜索各平台中老年爆款内容，提取选题模式和关键词 | 爆款选题库+关键词模式 + 原始爆款内容示例 |
| A3-节令日历 | 构建全年52周内容日历，绑定节气/节日/时令 | 全年节令内容日历 + 节令内容示例 |
| A4-年龄段偏好 | 分析3个年龄段的内容偏好差异 | 年龄段×品类偏好矩阵 + 原始偏好数据 |
| A5-平台适配 | 分析各平台中老年内容形式特征和算法偏好 | 平台适配指南 + 原始爆款标题数据 |
| A6-标题公式 | 彐纳中老年爆款标题句式模式 | 标题公式库 + 分类标题示例集 |
| A7-竞品账号 | 搜索各平台头部中老年账号，分析选题分布 | 竞品账号分析报告 + 竞品账号内容摘录 |

汇总后由主Agent整合为最终素材库，按标准格式组织全部1095条素材。

## 排除内容

- 政治类话题（政策评论、时政分析）
- 新闻类内容（社会新闻、突发事件报道）
- 任何需要新闻资质或专业资质才能发布的领域
