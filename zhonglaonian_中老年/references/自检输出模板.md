# 自检输出模板

完成四层自检后，在文章末尾附一份简洁质检报告：

```
## 质检报告

**L1 硬性规则** ✅/❌
- 禁用词：X处命中（已修复/待修复）
- 禁用标点：X处命中（已修复/待修复）
- 结构套话：X处命中（已修复/待修复）
- 空泛工具名：X处（已修复/待修复）

**L2 风格一致性** ✅/❌
- 开头：✅/❌
- 节奏：✅/❌（具体问题：...）
- 口语化：✅/❌（使用了X个口语词组）
- 标点禁令二次确认：✅/❌

**L3 内容质量** ✅/❌
- 观点支撑：✅/❌
- 知识输出：✅/❌
- 文化升维：✅/❌
- 对立面与同理心：✅/❌
- 类型专项：✅/❌
- 逐一展示：✅/❌/不适用

**L4 活人感** ✅/❌
- 温度感：✅/❌（具体段落：...）
- 独特性：✅/❌
- 姿态：✅/❌
- 心流：✅/❌（断点位置：...）

**总评**：4层全部通过 / X层需要返工
**修复优先级**：[列出最需要修复的1-3个具体问题]
```

## L1 禁用词替换对照表

| 禁用词 | 替换为 |
|--------|--------|
| 说白了 | 坦率的讲 / 其实就是 |
| 意味着什么 / 这意味着 | 那结果会怎样呢 / 所以呢 |
| 本质上 | 说到底 / 其实 |
| 换句话说 | 你想想看 / 也就是说 |
| 不可否认 | 直接删掉换正面陈述 |
| 综上所述 | 具体的回扣句 |
| 总的来说 | 自然转场词 |
| 首先...其次...最后 | 删掉直接说 |
| 值得注意的是 | 删掉直接说 |
| 不难发现 | 删掉直接说 |

## L1 禁用标点替换对照表

| 禁用标点 | 替换为 |
|----------|--------|
| 冒号"：" | 逗号"," |
| 破折号"——" | 逗号或句号 |
| 双引号""或"" | 「」或不加引号 |

## L1 结构套话扫描清单

- "让我们来看看"
- "接下来让我们"
- "在当今...的时代"
- "随着...的发展"
- 连续bullet point超过3个
- 大段加粗超过2行
