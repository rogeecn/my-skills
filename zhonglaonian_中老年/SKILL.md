# 中老年赛道内容创作

## 状态数据分离

**SKILL 是只读资产，不含状态。** 运行时数据存放在 `workspace/.zhonglaonian_中老年/` 下：

- 只读资产：本目录下所有文件（SKILL.md、references/）不可写
- 运行状态：`workspace/.zhonglaonian_中老年/output/`（创作输出）、`workspace/.zhonglaonian_中老年/content_history.json`（近30篇记录，读写）
- 环境变量：`workspace/.env`

## 概述

**选题 → 创作 → 风格增强 → 自检 → 保存** 五阶段十步技能。支持单篇和系列连载。推导基于交叉矩阵和references数据文件，创作后自动记录近30篇章历史防同质化。风格增强注入活人感手法，自检用四层质检体系确保无AI味。

## 第一阶段：选题

### 步骤1：确定上下文

选题前确定4个上下文因素：

1. **当前时令** — 读 `全年节令日历.yaml`，定位当前周的节气、节日、时令标签
2. **生命事件** — 询问受众是否经历某个生命事件（退休/带孙/出院/丧偶等），读 `生命事件维度.yaml`。**生命事件优先级高于时令**
3. **目标年龄段** — 询问面向哪个年龄段，或根据用户描述推断：
   - 用户说"老年人""老人""年纪大的""70多岁的"→ 优先 **65-80**
   - 用户说"中年""50多岁""刚退休"→ 优先 **55-70**
   - 用户说"40多岁""50出头""还没退休"→ 优先 **45-60**
   - 未指定时默认三档轮转各产一条
4. **品类偏好** — 询问感兴趣品类，或读 `年龄段偏好矩阵.yaml` 按关注度自动分配

### 步骤2：生成3-5个选题

三种推导公式：

- **基础选题**: A_子品类 × B_年龄段 × C_时令 — 读 `交叉矩阵模板.yaml`
- **事件选题**: A_子品类 × B_年龄段 × C2_生命事件 — 读 `生命事件维度.yaml`
- **交叉选题**: A1_子品类 × A2_子品类 × B_年龄段 × (C | C2) — 读 `跨品类交叉规则.yaml`

**每批必须含：至少1个交叉选题 + 至少1个时令或事件绑定选题。**

每个选题必须含：

| 字段 | 来源 |
|------|------|
| 选题名称 | 交叉推导结果 |
| 推荐理由 | 引用年龄段偏好矩阵的切入角度 |
| 目标年龄段 | B_年龄段+核心心态 |
| 时令/事件关联 | C_养生方向+情感关键词 或 C2_核心场景 |
| 长尾关键词 | `长尾关键词总表.yaml`取2-3个 |
| 品类关注度 | `年龄段偏好矩阵.yaml`读取 |
| 选题类型 | 标注"基础/事件/交叉" |

**多样性规则：** 3-5个选题必须覆盖不同品类和不同年龄段。

### 步骤3：去重审核（Guarder）

选题生成后、呈现给用户前**必须执行**：

1. 读 `content_history.json`
2. 与近30篇对比检查：
   - 子品类出现≥5次→该子品类降权
   - 年龄段出现≥10次→该年龄段降权
   - 核心主题重复3次→该主题降权
   - 焦虑型>60%→优先赋能型和温暖型
   - 标题公式≥3次降权，≥5次禁用
3. 替换重复选题为低频品类/年龄段/基调新选题
4. 向用户说明调整结果

**全部重复时：** 如果所有候选选题都有重复风险，扩大搜索范围——尝试未使用过的低频品类组合，或切换到生命事件维度中未覆盖的事件类型。

### 步骤4：呈现选题

用 `question` 工具呈现，格式见SKILL.md中的示例。允许用户选择其一或换一批。

**系列触发：** 连续3次选同品类/年龄段，或用户提到"做几天""系列""一周内容"，建议切换系列模式（读 `内容系列模板.yaml`）。

## 第二阶段：创作

### 步骤5：选择叙事基调

读 `正向叙事模板.yaml` 中的选择规则：

| 条件 | 基调 |
|------|------|
| 65-80岁 | 禁止纯焦虑，必须赋能或温暖 |
| 55-70岁 | 可焦虑开头+赋能中段 |
| 45-60岁 | 焦虑型和赋能型各半 |
| 交叉选题 | 一律赋能型 |
| 丧偶事件 | 一律温暖/共鸣 |
| 住院出院 | 可焦虑开头+赋能结尾 |
| 退休事件 | 优先赋能型 |

### 步骤6：推导文章各部分

**标题：** 选题 × (D标题公式 | D2赋能公式) × (E情感触发 | E2赋能触发) → 5-8个变体。从 `标题公式库.yaml` 和 `正向叙事模板.yaml` 选取兼容公式，检查品类和年龄段约束。

**大纲：** 选题 × B年龄段 × 叙事基调 → 大纲框架（焦虑型3种/赋能型3种）

**交叉选题篇幅规则：** A1×A2两品类必须各占≥30%篇幅。大纲中至少1个要点展开A1核心方法，至少1个展开A2价值贡献。开头段落必须同时提及两品类关键词。

**开头：** 选题 × 情感触发 × B年龄段 → 开头段落（5种原有触发+2种赋能触发）

**平台适配：** 读 `平台适配指南.yaml`

### 步骤7：风格增强（活人感注入）

初稿完成后，读 `写作风格库.md`，逐段检查判断是否需要增强，局部改写。不是全文重写。

**核心手法（每篇至少5种）：**

1. **口语化转场**：把"接下来让我们讨论"换成"说到这个""你想想看""说真的"
2. **节奏断裂**：情绪高点用极短句独立成段，全文至少3处。中老年选温暖/感慨型："真的是一声叹息。""岁月啊。"
3. **知识随手掏**：不是"下面科普一下"，而是"我突然想起一个东西，这玩意叫xxx"
4. **自嘲与真实暴露**：中老年赛道用温和自嘲——"说实话我也不太懂""我自己也踩过坑"，不用网络语
5. **疑问句刹车**：用疑问句让读者停一秒接收新信息——"为啥xxx会有效果呢？"

**推荐补充（择机使用）：**

6. 扣主线句（偏离主线后一句话拉回来）
7. 文化升维（中老年选熟悉参照物：中医典故、历史故事、经典诗词，不用赛博朋克/格式塔心理学）
8. 回环呼应（开头留钩子结尾callback）
9. 谦逊铺垫（"我自己也有一些不成熟的经验"）
10. 读者直呼（精准投放"屏幕前的你""你相信我"）
11. 人物画像法（3-5句让人物立体）
12. 句式故意打破（重复强调、中途模糊、省略主语）
13. 情绪标点（中老年赛道偶尔用"。。。"表示感慨，不频繁用"？？？""= ="）
14. 逐一展示升番逻辑（最基础→最惊人逐层升级）

**绝对禁区（暴露AI味）：**

1. 禁用套话："首先其次最后""综上所述""值得注意的是""不难发现""让我们来看看""接下来让我们"
2. 不用bullet point罗列、不大段加粗。公众号长文无小标题，靠节奏和转场推进。唯一例外是"N条方法"分条目结构用数字编号
3. **标点禁令**：正文禁止冒号（→逗号）、破折号（→逗号或句号）、双引号（→「」或不加引号）
4. 禁用踩雷词："说白了""意味着什么""本质上""换句话说""不可否认"
5. 不用"比如有一次..."编造场景，用邻居/亲友故事替代
6. 不说"AI工具""某个模型"，说具体名字
7. 禁止教科书开头："在当今快速发展的时代""随着技术的不断进步"，永远从具体场景切入

### 步骤8：四层自检

风格增强完成后必须跑完四层质检。自检输出格式见 `references/自检输出模板.md`。

**L1 硬性规则（零命中才通过）：**
- 禁用词扫描 → 替换（对照表见自检输出模板）
- 禁用标点扫描 → 替换
- 结构套话扫描 → 替换
- 空泛工具名检查 → 替换

**L2 风格一致性（L2-1全部通过，其余至少3/4）：**
- 开头是否从具体场景切入？第一句是否制造"然后呢"冲动？
- 节奏：长短句交替？3+处断裂？扣主线句？疑问句刹车？无小标题？
- 口语化：8-10个不同表达？至少一处自嘲？标点表达情绪？
- 标点禁令二次确认

**L3 内容质量（L3-1/2必须通过，其余至少通过相关项）：**
- 观点支撑：具体人/场景/细节？
- 知识输出："聊着聊着顺手掏出"？无教科书式科普？
- 文化升维：至少一处自然连接？
- 对立面与同理心：先站到读者处境再给视角？
- 选题类型专项：养生类有邻居故事？家庭类有情感细节？退休类有心理描写？交叉类双品类各30%？
- 逐一展示升番逻辑？

**L4 活人感终审（整体感觉"像真人写的"）：**
- 温度感：体感记忆还是知识性描述？
- 独特性：只有这个号才写出的角度？
- 姿态：有见识的普通人认真聊事？无导师/营销姿态？
- 心流：从头到尾无注意力断点？

**自检失败恢复：** L1不通过→修到零命中再继续；L2-L3不通过→针对性补强后重跑L1-L3；L4不通过→返工风格增强步骤7。

### 步骤9：保存文件

1. 从选题提取slug
2. 创建目录并保存两个文件：

**plan.md** — 完整创作过程（选题推导、大纲、标题备选、平台适配、正文草稿、质检报告）

**article.md** — YAML front matter + 800-1500字正文。front matter必须含：title/slug/date/age_group/topic_type/sub_category/seasonal_tag/life_event/cross_categories/narrative_tone/keywords/title_formula_used/platforms

3. 追加创作记录到 `content_history.json`（含date/slug/title/topic_type/sub_category/age_group/seasonal_tag/life_event/cross_categories/narrative_tone/title_formula_used/keywords）
4. 裁剪content_history：超过30条删除最旧条目

### 步骤10：完成后提供选项

继续选题 | 修改当前文章 | 批量生成（系列模式） | 查看近30篇记录

## 约束

- 禁止涉及政治、新闻等需资质内容
- 标题公式和情感触发必须与品类/年龄段兼容
- 每批选题覆盖不同品类和年龄段，至少1个交叉选题
- 生命事件优先高于时令
- 去重审核必须执行（标题公式≥3次降权≥5次禁用）
- 交叉选题两品类各占≥30%篇幅
- 65-80岁禁止纯焦虑，交叉选题一律赋能型
- 风格增强必做（≥5种手法），自检必做（四层全通过）
- 正文禁止冒号、破折号、双引号；禁用词零容忍
