## 步骤1：筛选合适的元素

### 1.1 确定主题来源

读取【全年节庆纪念日日历】和【时事热点素材库】，确定主题来源：

| 来源 | 示例 |
|------|------|
| 用户直接指定 | "做一张端午节手抄报" → 主题=端午 |
| 当前日期匹配 | 5月14日 → 临近母亲节(5/10)+防灾减灾日(5/12)+525心理健康(5/25) |
| 时事热点匹配 | 航天发射 → 中国航天主题 |
| 生命事件触发 | 开学季 → 新学期手抄报 |

### 1.2 按主题筛选适配元素

读取【元素筛选指南】和【视觉元素库】，按主题动态筛选。交叉主题时读取【内容品类交叉矩阵】的交叉组合和黑马组合部分：

**筛选5类元素（新增色彩筛选）：**

| 元素类 | 筛选方法 | 筛选产出 |
|--------|---------|---------|
| 边框花边 | 主题×边框适配关系，选出2-3个适配边框 | 如端午→[端午边框, 夏花边框, 青花纹边框] |
| 色彩方案 | 读【视觉元素库】主题色彩快速查找表 + 【元素筛选指南】色彩筛选决策树，选出2-3组配色 | 如端午→[深绿+金+米白, 绿+浅蓝+白, 深绿+金+深蓝] |
| 装饰点缀 | 主题×装饰适配关系，选出2-3组装饰 | 如端午→[龙舟+粽子+艾草+香囊, 荷花+蜻蜓+夏花+云朵, 青花纹+书卷+印章+桂花] |
| 内容素材 | 主题×内容角度适配关系 + 交叉组合，选出2-3个内容角度 | 如端午→[起源故事+习俗+诗词, 屈原+龙舟+粽子科学, 南北差异+当代+儿童视角] |
| 插图类型 | 读【视觉元素库】插图类型分类体系，确定插图类型组合(场景图/对比图/装饰性插图) | 如端午→[场景图为主(龙舟竞渡)+1处装饰性插图(粽子图标)] |

**筛选原则：**
- 每类元素给2-3个选项，**不锁死**，供步骤2动态组合
- 选项之间要有明显差异（不同氛围：庄重/活泼/清新/温暖）
- 交叉主题时，从【品类交叉矩阵】的交叉组合和黑马组合中取元素混合，同时参照"交叉组合→版面风格映射"确定推荐布局

### 1.3 呈现筛选结果

向用户展示筛选出的元素清单，格式：

```
主题: 端午节
适配边框: [端午专属边框 | 夏花自然边框 | 青花纹文雅边框]
适配色彩: [深绿+金(传统) | 绿+浅蓝+白(清新) | 深绿+金+深蓝(厚重)]
适配装饰: [龙舟+粽子+艾草+香囊(传统) | 荷花+蜻蜓+云朵(自然) | 青花纹+书卷+印章(文雅)]
适配内容角度: [起源故事+习俗+诗词 | 屈原+龙舟+粽子科学 | 南北差异+当代+儿童视角]
适配插图类型: [场景图(龙舟竞渡) + 装饰性插图(粽子图标)]
推荐布局(来自交叉组合→版面风格映射): 四宫格型/三区均衡型
```

## 步骤2：确定风格

### 2.1 确定年级/受众

读取【受众画像矩阵】，根据用户需求或默认确定年级：
- 低年级(1-2)：图案为主、文字极少、卡通风格
- 中年级(3-4)：图文各半、内容丰富、过渡风格  
- 高年级(5-6)：文字为主、深度内容、多元风格

**如用户未指定年级，询问用户。**

### 2.2 动态组合风格

**核心原则：风格不锁死，根据主题+年级+场景动态决定。**

根据步骤1筛选出的元素 + 年级适配规则，与用户交互确定风格组合：

| 风格维度 | 决定逻辑 | 参考来源 | 用户参与 |
|----------|---------|---------|---------|
| 插图风格 | 年级约束×主题氛围→动态选择。低年级限卡通Q版/简笔线条/卡通写实过渡；中年级可加水墨/扁平矢量；高年级可加写实素描 | 【视觉元素库】插图类型分类体系 | 用户可指定偏好 |
| 版面布局 | 年级约束×输出大小×内容量→动态选择。低年级简单大图型；中年级分区型；高年级复杂排版型 | 【视觉元素库】版面布局选择决策树 + 【品类交叉矩阵】交叉组合→版面风格映射 | 用户可指定偏好 |
| 标题字体 | 年级约束×插图风格→配套选择。卡通配圆体气泡字；水墨配书法体；写实配衬线体 | 【视觉元素库】标题字体风格 | 自动配套 |
| 边框选择 | 从步骤1筛选结果中，用户选择或AI推荐最适配项 | 【视觉元素库】边框花边体系 | 用户可指定偏好 |
| 色彩选择 | 从步骤1筛选结果中，用户选择或AI推荐最适配项 | 【视觉元素库】主题色彩快速查找表 | 用户可指定偏好 |
| 装饰选择 | 从步骤1筛选结果中，用户选择或AI推荐最适配项 | 【视觉元素库】装饰元素清单 | 用户可指定偏好 |
| 内容角度 | 从步骤1筛选结果中，用户选择或AI推荐最适配项 | 【元素筛选指南】主题×品类锚定 | 用户可指定偏好 |

**风格推荐策略：**
- 首次生成推荐"主题标配"组合（主边框+主色彩+传统装饰+主内容角度）
- 用户要求不重复时，从未选过的组合中推荐下一个
- 用户指定风格偏好时，按偏好组合

### 2.3 呈现风格方案

向用户展示确定的风格方案，格式：

```
年级: 中年级(3-4)
插图风格: 卡通写实过渡(身体比例真实但线条圆润)
版面布局: 四宫格型(四个等分区块)
标题字体: 手写体+渐变色填充
边框: 端午专属边框(龙舟粽子艾草香囊)
色彩: 深绿#228B22 + 金黄#FFD700 + 米白#F5F5DC
装饰: 龙舟+粽子+艾草+香囊
内容角度: 屈原故事+龙舟竞渡+粽子科学
```

询问用户是否确认，或需要调整哪些维度。

|----------|------|------|---------|
| A4横版 | 297×210mm / 1120×794px(300dpi) | 最常见的手抄报格式 | 个人作业、打印提交 |
| A4竖版 | 210×297mm / 794×1120px(300dpi) | 纵向排版 | 诗歌/时间轴/瀑布流型内容 |

| 全黑板 | 约2400×1200px | 整面黑板报 | 全班合作/重大节日 |

| B站横版 | 1920×1080px(16:9) | B站视频封面 | 教程视频封面 |

> 如用户未指定，默认A4横版。但**必须询问**——因为小红书/黑板报需求很常见。

### 3.2 平台适配调整

如输出目标为电子分享平台，读取【平台适配指南】进行适配：

| 平台 | 关键适配 |

### 3.4 与用户确认

## 步骤5：构建线稿+预览图

### 5.1 先查找相似场景参考

读取【场景图片描述库】，查找与当前主题最接近的已有场景描述。这些场景已经包含了完整的双轨描述（预览图+线稿），可以作为描述格式的参考模板。

**为什么要先读参考场景？** 场景图片描述库中的描述是经过验证的——它们有精确的版面布局命名、色号标注、插图位置描述、装饰数量控制、线稿线条层次规范。参照它们可以确保输出格式的一致性和专业性。

**查找逻辑：** 从描述库中找主题关键词最匹配的场景，参照其描述格式（不要照搬内容，只参照格式和细节粒度）。

### 5.2 生成线稿描述

基于步骤4确认的描述 + 参考场景的格式，构建**线稿专用描述**：

**线稿描述的核心规则——这是本skill最重要的差异化输出：**

| 规则 | 为什么重要 |
|------|---------|
| 纯黑白线条，无色彩填充 | 线稿是描摹模板，填色由学生自己完成 |
| 文字框正文区留空白，只写标题文字 | 线稿供手写填字，不是完整成品 |
| 线条4层层次：边框粗(2pt) > 标题中(1.5pt) > 内容框细(1pt) > 装饰最细(0.5pt) | 层次感让描摹时有明确的粗细参考，区分主次 |
| 插图只画轮廓线+关键结构线，不画细节填色 | 轮廓线是描摹起点，细节和填色留给学生创作 |
| 装饰3-5处，每处只画轮廓 | 过多装饰会让线稿混乱，3-5处恰好点缀 |
| 白色背景，无底色 | 线稿打印后白色背景供学生自由填色 |

**线稿描述必须以这句话开头：**
"一张小学生手抄报线稿，{输出目标}比例，{版面布局}。纯黑白线条画，无色彩填充，白色背景。线条层次分明："

**线稿描述必须包含这5个层次段落：**
1. 外边框：{边框花边轮廓线描述}，粗线(2pt)
2. 标题区域：{标题内容+字体轮廓}，中线(1.5pt)
3. 插图轮廓：{每幅插图只画外形轮廓线，不填色}，中线(1.5pt)
4. 文字框边线：{每个文字框边线+标题文字，正文区域留空白供手写}，细线(1pt)
5. 装饰轮廓：{3-5处装饰的轮廓线}，最细线(0.5pt)

**线稿描述必须以这句话结尾：**
"整体为可打印线稿模板，适合{年级}描摹填色填字。"

### 5.3 生成预览图描述

预览图 = 步骤4的完整描述，直接用于生成带色彩的完成效果图。

预览图让学生/家长看到完成后的效果，决定线稿是否满意。

### 5.4 SEO关键词融入

读取【长尾关键词总表】中与当前主题匹配的高搜索量关键词，在描述中自然融入：

- 预览图描述的标题中包含SEO关键词（如"端午节手抄报""端午手抄报简单漂亮"）
- 如输出目标为小红书/抖音等平台，在描述底部加入平台适配文案（如"XX手抄报模板分享")

### 5.5 输出交付

最终交付给用户两项内容：

1. **线稿图片描述**（纯黑白轮廓，可打印描摹，线条4层层次）
2. **预览图图片描述**（完整彩色效果，含色号标注）

两项描述均可直接用于图片生成API调用。

## 约束条件

1. 步骤1筛选元素必须给出2-3个选项，不锁死单一选择
2. 步骤2风格由主题+年级+用户偏好动态决定，不套预设列表。版面布局必须从【视觉元素库】决策树+【品类交叉矩阵】版面风格映射中选择
3. 步骤3必须明确输出目标和尺寸。如用户提到任何平台关键词，必须读取【平台适配指南】做适配
4. 步骤4描述必须包含：输出目标+版面布局(命名类型)+边框+色彩(色号)+标题风格+插图细节(位置/大小/内容/风格)+文字区(位置/标题/要点)+装饰(3-5处)+受众标注
5. 步骤5线稿描述必须去掉所有色彩，只保留轮廓线和结构线，文字框正文区留空白
6. 线稿线条层次分明：边框粗(2pt) > 标题中(1.5pt) > 内容框细(1pt) > 装饰最细(0.5pt)
7. 线稿描述必须以"一张小学生手抄报线稿..."开头，以"整体为可打印线稿模板..."结尾
8. 每次生成先确定当前日期对应节日(读日历)
9. 步骤5必须先读【场景图片描述库】找相似场景作为格式参考
10. 如输出目标为电子分享平台，描述中必须融入SEO关键词(从【长尾关键词总表】)
11. 绝对禁区：不可成人化/低俗/暴力/恐怖/版面填满/配色超5种/全文字无图/争议性宗教政治
12. 安全教育类(防溺水/防欺凌/防拐骗等)必须用温暖友好配色，不可用红色警示恐吓儿童

## 常见错误

| 错误 | 修正 |
|------|------|
| 步骤1只给1个选项锁死 | 必须给2-3个不同氛围的选项供选择 |
| 步骤2直接套预设风格列表 | 必须根据主题+年级+用户偏好动态组合，并参考决策树和版面风格映射 |
| 步骤3默认A4不问用户 | 必须询问输出目标，黑板报/小红书需求常见 |
| 步骤4描述笼统"画了龙舟" | 必须具体："左上区块：屈原投江场景简笔，屈原站汨罗江边..." |
| 步骤5线稿和预览图混在一起 | 线稿=纯黑白轮廓，预览图=完整彩色，必须分别构建 |
| 步骤5线稿仍有色号 | 线稿去掉所有色彩，只留黑白线条层次 |
| 步骤5线稿正文区写了完整文字 | 正文区留空白框供手写，只写标题文字 |
| 步骤5没有读场景描述库参考 | 必须先找相似场景参考其格式和细节粒度 |
| 步骤5装饰超过5处 | 线稿装饰3-5处，过多让描摹困难 |
| 安全教育用红色恐吓配色 | 改为天蓝+暖橙+白等温暖友好配色，让孩子愿意接近而非害怕 |
| 小红书输出用A4横版尺寸 | 必须用1080×1440px(3:4)竖版，文字精简2-3框 |
