# 白癜风和相关皮肤病 — 内容运营技能

## 核心创作原则（5条红线）

1. **专业感优先**：数据标注来源+证据等级标注+个体化标注。没有来源的数据不许出现在输出中。
2. **机制→临床桥梁**：复杂机制用故事法讲→临床用决策树/流程图落地→话术让患者可理解。
3. **全身管理思维**：从皮肤白斑引出甲状腺/心理等共病筛查，打破"只看皮肤"局限。
4. **预期管理核心**：治疗目标≠根治→稳定+复色→平台期≠失败→这四个等式必须在输出中体现。
5. **合规红线（8条硬性禁令）**：
   - 禁止"根治""治愈承诺"
   - 禁止推荐偏方
   - 禁止暗示"不治也会好"
   - 禁止过度展示恶化案例不加说明
   - 禁止将白癜风与"丑陋""缺陷"直接关联
   - 禁止忽视个体差异的模板化表述
   - 禁止无数据疗效断言
   - 禁止暗示患者"过错"导致白癜风

## 文章创作流程

### Step 1: 定位（读3个文件）

读取 `references/赛道定义.md` → 确定品类方向(P1-P12)
读取 `references/白癜风受众画像矩阵.yaml` → 确定受众层级(L1-L5)
读取 `references/白癜风内容品类交叉矩阵.yaml` → 确定品类×受众交叉组合

### Step 2: 选题（读2个文件）

读取 `references/白癜风全年节庆纪念日日历.yaml` → 检查时令节点是否可锚定
读取 `references/白癜风长尾关键词总表.yaml` → 嵌入SEO关键词

### Step 3: 标题（读2个文件）

读取 `references/白癜风标题公式库.yaml` → 选择标题公式+情感触发词
读取 `references/白癜风生命事件维度.yaml` → 匹配临床场景触发器

### Step 4: 正文（读3个文件）

读取 `references/白癜风正向叙事模板.yaml` → 选择叙事大纲+基调
读取 `references/白癜风写作风格库.md` → 选择写作手法(13种)
读取 `references/白癜风平台适配指南.yaml` → 适配发布平台规格

### Step 5: 知识支撑（按品类需要选读）

| 品类 | 需额外读取 |
|------|-----------|
| P3治疗方案/P4新药前沿 | `references/白癜风药物管线追踪.yaml` |
| P9案例分享 | `references/白癜风经典病例库.yaml` |
| P10指南解读 | `references/白癜风国际指南对比.yaml` |
| 任何涉及医学事实的内容 | `references/白癜风基础知识库.yaml` |
| P5患者教育/P6心理干预 | `references/白癜风竞品账号分析.yaml`(差异化定位) |

### Step 6: 去重

读取 `workspace/.baidfeng/content_history.json` → 检查近30篇记录避免重复

### Step 7: 写作+输出

按【文章输出格式】输出完整文章。写完后追加记录到 `workspace/.baidfeng/content_history.json`。

## 输出格式定义

### 文章输出格式

每篇文章必须包含以下结构：

```
# {标题}（标题公式+情感触发词组合）

> 本文仅为科普，不构成医疗建议

## 引入段（150-200字）
{痛点共鸣/悬念抛出/背景铺垫——建立阅读动机}

## 正文段（按写作手法展开）
{核心内容——每200字配1张内容图指示（数据卡片/流程图/对比表/清单）}

## 实操转化段（100-200字）
{2-5条可执行建议——清单形式}

## 正向收束段（100-150字）
{安心话术——"可控可治/多数稳定/有方案可选/生活照常"}

## 合规声明
本文仅为科普，不构成医疗建议。具体诊疗请遵医嘱。

---
**创作元数据**（必填，便于去重追踪）
- 品类: {P编号+名称}
- 受众: {L编号+名称}
- 标题公式: {F编号+名称}
- 情感触发词: {类别+具体词}
- 写作手法: {编号+名称}
- 发布平台: {平台名}
- 字数: {实际字数}
```

- 时长: {目标时长}
