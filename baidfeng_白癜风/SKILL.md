## 技能概述

本技能为白癜风和相关皮肤病赛道提供完整的内容运营框架，从受众定义、品类体系、选题方向到写作风格、平台适配和竞品分析，覆盖内容创作全链路。

核心差异化：以**专业感**为风格基调，打破"只看皮肤"局限，建立**全身管理思维**，通过**机制→临床→话术**的桥梁让专业内容可理解、可操作、可传播。

## 使用流程

### 1. 选题阶段
读取 `赛道定义.md` → 确定目标受众和品类方向
读取 `白癜风受众画像矩阵.yaml` → 选择具体受众层级
读取 `白癜风内容品类交叉矩阵.yaml` → 确定品类和交叉组合
读取 `白癜风全年节庆纪念日日历.yaml` → 检查时令节点
读取 `白癜风长尾关键词总表.yaml` → 嵌入SEO关键词

### 2. 标题阶段
读取 `白癜风标题公式库.yaml` → 选择标题公式+情感触发词
读取 `白癜风生命事件维度.yaml` → 匹配临床场景触发器

### 3. 正文阶段
读取 `白癜风正向叙事模板.yaml` → 选择叙事大纲+基调
读取 `白癜风写作风格库.md` → 选择写作手法
读取 `白癜风平台适配指南.yaml` → 适配发布平台

### 3a. 视频创作阶段（视频内容时额外读取）
读取 `白癜风视频导演手册.md` → 选择场景类型+运镜语言+构图+节奏模板+出镜规范+BGM+字幕+封面
读取 `白癜风视频脚本模板.yaml` → 选择脚本类型(T1-T6)+填写分镜/口播/画面指示

### 3b. 图文创作阶段（小红书/知乎图文内容时额外读取）
读取 `白癜风图文视觉规范.yaml` → 选择配色/字体/图标+结构模板+排版规则+图片标准

### 4. 去重阶段
读取 `workspace/.baidfeng/content_history.json` → 检查近30篇记录避免重复

### 5. 发布后
追加记录到 `workspace/.baidfeng/content_history.json`

## 核心创作原则

1. **专业感优先**：数据标注来源+证据等级标注+个体化标注
2. **机制→临床桥梁**：复杂机制用故事法讲→临床用决策树/流程图落地
3. **全身管理思维**：从皮肤白斑引出甲状腺/心理等共病筛查
4. **预期管理核心**：治疗目标≠根治→稳定+复色→平台期≠失败
5. **合规红线**：禁止根治承诺/偏方推荐/暗示患者过错/无数据断言
