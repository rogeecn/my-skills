# 中老年赛道内容创作

## 概述

**选题 → 创作 → 去重审核 → 风格增强 → 自检 → 保存** 六阶段技能。支持单篇和系列连载两种输出模式。所有推导基于交叉矩阵和references目录下的数据文件，创作完成后自动记录到近30篇章历史中防止同质化。风格增强阶段会注入活人感写作手法（口语化、节奏断裂、文化升维等），自检阶段用四层质检体系确保成品无AI味。

## 第一阶段：选题

### 步骤1：确定上下文

选题前，先确定4个上下文因素：

1. **当前时令** — 读取 `references/全年节令日历.yaml`，定位当前周的节气、节日、时令标签
2. **生命事件** — 询问用户或受众是否正在经历某个生命事件（退休、带孙、出院、丧偶等），读取 `references/生命事件维度.yaml`。**生命事件优先级高于时令**——当有事件时优先选取事件相关选题
3. **目标年龄段** — 询问面向哪个年龄段（45-60 / 55-70 / 65-80），或默认三档轮转各产一条
4. **品类偏好** — 询问感兴趣的品类，或读取 `references/年龄段偏好矩阵.yaml` 按关注度自动分配

### 步骤2：生成3-5个选题

选题推导公式扩展为三种：

- **基础选题**: `A_子品类 × B_年龄段 × C_时令周期` — 读取 `references/交叉矩阵模板.yaml`
- **事件选题**: `A_子品类 × B_年龄段 × C2_生命事件` — 读取 `references/生命事件维度.yaml`
- **交叉选题**: `A1_子品类 × A2_子品类 × B_年龄段 × (C_时令 | C2_生命事件)` — 读取 `references/跨品类交叉规则.yaml`

**每批3-5个选题中必须包含：至少1个跨品类交叉选题 + 至少1个与时令或生命事件绑定的选题。**

每个选题必须包含以下字段：

| 字段 | 数据来源 |
|------|----------|
| 选题名称 | 交叉推导结果（基础/事件/交叉） |
| 推荐理由 | 引用年龄段偏好矩阵的切入角度，说明该组合为何有效 |
| 目标年龄段 | B_年龄段及其核心心态描述 |
| 时令/事件关联 | C_时令的养生方向和情感关键词，或C2_生命事件的核心场景 |
| 长尾关键词 | 从 `references/长尾关键词总表.yaml` 取该子品类×年龄段的2-3个关键词 |
| 品类关注度 | 从 `references/年龄段偏好矩阵.yaml` 读取关注度等级 |
| 选题类型标注 | 标注"基础/事件/交叉"，方便后续叙事基调选择 |

**多样性规则：** 3-5个选题必须覆盖不同品类和不同年龄段，禁止全部来自同一品类或同一年龄段。

### 步骤3：去重审核（Guarder）

选题生成后、呈现给用户前，**必须执行去重审核**：

1. 读取 `content_history.json`
2. 将每个候选选题与近30篇章记录对比，检查以下维度是否重复：
   - **子品类重复** — 近30篇中同一A_子品类出现≥5次，该子品类降权（不再选入本轮）
   - **年龄段重复** — 近30篇中同一B_年龄段出现≥10次（占比超33%），该年龄段降权
   - **选题核心主题重复** — 近30篇中有相同核心主题（如"失眠"出现3次），该主题降权
   - **叙事基调重复** — 近30篇中焦虑型>60%，本轮优先赋能型和温暖型
   - **标题公式重复** — 近30篇中同一标题公式出现≥3次，该公式本轮降权（优先选用低频公式）；出现≥5次，该公式本轮禁用
3. 如发现重复风险，替换重复选题为低频品类/年龄段/基调的新选题
4. 向用户说明去重调整结果

### 步骤4：呈现选题供用户选择

使用 `question` 工具呈现。格式示例：

```
【选题1】(交叉) 和老伴一起学摄影——退休后不吵架了
  推荐理由: 家庭关系×兴趣娱乐跨品类交叉，用共同活动修复夫妻关系比说教更有效
  目标年龄段: 55-70岁（核心心态：我在适应新生活，需要实用指导）
  事件关联: 正式退休日 — 情感关键词：自由、新开始、第二人生
  长尾关键词: 退休后夫妻怎么相处, 老伴一起学东西, 退休不吵架
  品类关注度: 高（家庭关系 × 55-70）+ 中（兴趣娱乐 × 55-70）
  选题类型: 交叉选题 | 建议叙事基调: 赋能型

【选题2】(事件) 退休第一天怎么过不慌
  推荐理由: 55-70岁核心痛点是退休适应，退休日是流量爆发期
  ...
```

允许用户选择其一，或要求换一批。

**系列触发检查：** 如果用户连续3次选择同品类/同年龄段选题，或用户提到"做几天"、"系列"、"一周内容"，建议切换到系列模式（读取 `references/内容系列模板.yaml`）。

## 第二阶段：创作

### 步骤5：选择叙事基调

根据选题类型和年龄段选择基调，读取 `references/正向叙事模板.yaml` 中的选择规则：

| 条件 | 基调要求 |
|------|----------|
| 65-80岁选题 | 禁止纯焦虑触发，必须搭配赋能或温暖成分 |
| 55-70岁选题 | 可焦虑开头但中段必须转为赋能叙事 |
| 45-60岁选题 | 焦虑型和赋能型各占一半 |
| 跨品类交叉选题 | 一律使用赋能型叙事 |
| 丧偶类事件 | 一律温暖/共鸣，禁止焦虑 |
| 住院出院类 | 可焦虑开头+赋能结尾 |
| 退休类事件 | 优先赋能型 |

### 步骤6：推导文章各部分

**标题推导：** `选题 × (D_标题公式 | D2_赋能公式) × (E_情感触发 | E2_赋能触发) → 5+标题变体`
- 从 `references/标题公式库.yaml` 和 `references/正向叙事模板.yaml` 中选取兼容公式
- 必须检查适用品类和适用年龄段约束
- 共生成5-8个标题变体

**大纲推导：** `选题 × B_年龄段 × 叙事基调 → 大纲框架`
- 焦虑型大纲（原有3种：预防型/管理型/应对型）
- 赋能型大纲（新增3种，见 `references/正向叙事模板.yaml`）

**交叉选题正文篇幅分配规则：** 当选题类型为"交叉"（A1×A2两品类交叉）时，大纲和正文中两品类必须各占至少30%篇幅。不能只展开一个品类而另一个只做点缀。具体做法：
- 大纲主体要点中，至少1个要点专门展开品类A1的核心方法，至少1个要点专门展开品类A2的价值贡献
- 正文草稿中，品类A1的关键内容（方法/数据/案例）和品类A2的关键内容（体验/转变/证据）各占约35-40%，剩余20-30%为两者的连接过渡
- 开头段落必须同时提及两品类关键词，让读者立刻感知"这不是单品类内容"
- 示例：选题"和老伴一起学摄影——退休后不吵架了"，正文不是只讲摄影技巧，而是30%讲摄影怎么学+30%讲夫妻互动怎么改善+20%讲两者如何互相促进

**开头推导：** `选题 × 情感触发 × B_年龄段 → 开头段落`
- 5种原有触发（焦虑/共鸣/好奇/权威/温暖）
- 2种赋能触发（赋能触发/温暖成就触发），模板见 `references/正向叙事模板.yaml`

**平台适配：** 读取 `references/平台适配指南.yaml`

### 步骤7：风格增强（活人感注入）

初稿完成后，读取 `references/写作风格库.md`，对正文草稿进行风格增强。这是把"AI写的合格文章"变成"像是真人在跟你聊"的关键一步。

风格增强不是全文重写，而是在初稿基础上做精准改写。逐段检查，对每一段判断是否需要增强，然后局部改写。

**必须增强的手法（每篇至少使用5种）：**

- **口语化转场**：把"接下来让我们讨论"换成"说到这个""回到xxx这块""顺着上面的再聊聊"。转场词组库见写作风格库
- **节奏断裂**：在情绪高点或转折点，用极短的句子独立成段制造停顿。全文至少出现3处。比如"真的就是一声叹息。""大时代啊，朋友们。"
- **知识随手掏**：把"下面我来科普一下xxx"改成"我突然想起来一个东西，这玩意叫xxx"。知识点必须像聊着聊着自然想起来的，不是特意去查的
- **自嘲与真实暴露**：至少一处承认不足或自嘲。"说实话我也不确定""我自己也还在摸索""愚钝如我"。展示真实脆弱比假装全知更有说服力
- **句式故意打破**：在展开观点时加入口语打断——重复强调（"就是...就是...就是单纯的"）、中途模糊（"我就不说是谁了"）、省略主语（"想看看"而非"想要了解一下")
- **扣主线句**：偏离主线的段落后面必须有一句话拉回来，不需要长，一句就够，但频率要高
- **疑问句刹车**：用疑问句让读者停一秒准备接收新信息。"为啥xxx会有效果呢？""听着很难理解对吧。我还是用大白话举个例子。"
- **文化升维**：从具体事件连接到一个更大的文化/哲学/历史参照物。不是硬凑，是"聊着聊着自然想到了"的感觉。比如从退休适应联想到《北京折叠》的信息分层
- **人物画像法**：从一个数据点想象背后那个具体的人的完整人生。触发点数据→快速代入→多维堆砌→情感锚定→细节具象化，3-5句话让人物立体
- **回环呼应**：开头或中间留一个意象/句子/小钩子，结尾callback回来。让文章从「信息流」变成「作品」
- **谦逊铺垫**：给出观点前先用自谦降低防御心。"我也不知道行不行""我自己也有一些不成熟的经验"
- **读者直呼**：在关键节点直接跟读者对话。"屏幕前的你""你相信我""你也可以回想一下"——不是通篇都用，是精准投放
- **情绪标点**：用"。。。"表示语气拖长/震惊/无语，用"？？？"表示极度惊讶，用"= ="表示无语吐槽。这些标点是情绪的具象化

**中老年赛道的风格适配提醒：**

卡兹克写作风格的核心原则是"活人感"，但中老年受众有特殊偏好，需要适度调整：

- 口语化程度要更高：中老年读者对书面语更排斥，"坦率的讲""说真的""你想想看"这类词比卡兹克原文更密集使用
- 自嘲要温和：不用"老阴逼""尼玛"这类网络语，换成"说实话我也不太懂""我自己也踩过坑"
- 情绪标点适当减少：不频繁使用"？？？""= ="，偶尔用"。。。"表示感慨即可
- 文化升维选中老年熟悉的参照物：不用赛博朋克、格式塔心理学，用《北京折叠》、老电影、经典诗词、中医典故、历史故事
- 节奏断裂的短句选温暖/感慨型：不用"黑暗森林"，用"真的是一声叹息。""岁月啊。""后半辈子的事。"
- 逐一展示用升番逻辑：展示多个方法/案例时，从最基础到最惊人逐层升级，最炸的留到最后

**绝对禁区（这些是暴露AI味的地方，必须避免）：**

1. **套话**：禁用"首先...其次...最后"、"综上所述"、"值得注意的是"、"不难发现"、"让我们来看看"、"接下来让我们"
2. **过度结构化**：不用bullet point罗列观点，不大量加粗。公众号长文绝大多数时候没有小标题，从头到尾一口气顺下来，靠节奏和转场自然推进。唯一例外是"N条心得/方法"这种分条目结构才用数字编号
3. **标点禁令**：不使用冒号"："（用逗号代替），不使用破折号"——"，不使用任何双引号（需要引用时用「」或直接不加引号）
4. **高频踩雷词**：禁用"说白了""意味着什么""这意味着""本质上""换句话说""不可否认"
5. **假设性例子**：不用"比如有一次..."这种编造场景，用"就像我邻居张阿姨最近遇到的"这种真实感的细节（中老年赛道可以用邻里/亲友故事替代卡兹克的亲自下场）
6. **空泛工具名**：不说"AI工具""某个模型"，说具体名字
7. **教科书开头**：禁止"在当今快速发展的时代""随着技术的不断进步"这类空话开头。永远从一个具体的、当下的事件或场景切入

### 步骤8：四层自检体系

风格增强完成后，必须跑完四层质检流程。每一层都有明确的通过标准，只有四层全部通过，文章才算达标。

**L1 硬性规则检查（自动扫描层）**

- **L1-1 禁用词扫描**：全文搜索"说白了""意味着什么""这意味着""本质上""换句话说""不可否认""综上所述""总的来说""首先...其次...最后""值得注意的是""不难发现"，出现则必须替换。替换对照：→ 坦率的讲/其实就是 → 那结果会怎样呢/所以呢 → 说到底/其实 → 你想想看/也就是说 → 直接删掉换正面陈述 → 具体的回扣句 → 自然转场词 → 删掉直接说
- **L1-2 禁用标点扫描**：全文搜索冒号"："（→逗号）、破折号"——"（→逗号或句号）、双引号""或""（→「」或不加引号），出现则替换
- **L1-3 结构性套话扫描**：检查"让我们来看看""接下来让我们""在当今...的时代""随着...的发展"、连续bullet point超过3个、大段加粗超过2行
- **L1-4 工具名检查**：确认所有AI工具/产品使用具体名称，无"AI工具""某个模型"等空泛表述

通过标准：以上四项零命中。

**L2 风格一致性检查（模式匹配层）**

- **L2-1 开头检查**：是否从具体事件/场景切入（非宏大叙事）？第一句话是否让读者产生"然后呢？"的冲动？有无教科书式开头？
- **L2-2 节奏与结构**：有无长短句交替？有无一句话独立成段的断裂效果（至少3处）？偏离主线段落后面有无扣主线句？有无疑问句制造节奏刹车？是否避免了不必要的小标题（靠口语化转场衔接）？
- **L2-3 口语化检查**：是否使用了推荐口语化词组（至少8-10个不同表达）？有无论述中的故意打破？有无至少一处自嘲或承认不足？标点是否表达情绪？
- **L2-4 标点禁令二次确认**：AI容易在修改过程中重新引入禁用标点，需二次确认全文无冒号、破折号和双引号

通过标准：L2-1全部通过，L2-2至少3/4，L2-3至少3/4，L2-4通过。

**L3 内容质量检查（深度审查层）**

- **L3-1 观点支撑**：每个核心观点有无具体人/场景/细节/数据支撑？有无空泛论断？
- **L3-2 知识输出方式**：知识点是否"聊着聊着顺手掏出来"？有无教科书式科普？
- **L3-3 文化升维**：有无至少一处从具体事件连接到更大的文化参照物？连接是否自然？
- **L3-4 对立面与同理心**：讲核心观点时有无对对方立场的理解和承认？有无先站到读者处境里再给视角？
- **L3-5 选题类型专项**：根据选题类型做针对性检查——养生类有无真实案例/邻居故事？家庭类有无情感细节？退休类有无真实心理描写？跨品类交叉有无双品类各占30%篇幅？
- **L3-6 逐一展示**：涉及多个方法/案例对比时，是否逐一展示（每个带点评）而非一次性罗列？排列是否遵循升番逻辑（最基础→最惊人）？

通过标准：L3-1和L3-2必须通过，L3-3至L3-6至少通过相关项。

**L4 活人感终审（最终人格层）**

以读者视角通读全文，回答核心问题："读完这篇文章，我感觉是一个有见识的普通人在认真跟我聊一件打动他的事，还是一个AI在给我输出信息？"

- **L4-1 温度感**：情绪表达是体感记忆（"我当时就愣住了""鼻子一酸"）还是知识性描述（"我感到非常震撼"）？
- **L4-2 独特性**：这篇文章是否有"只有这个号才会写出来的角度"？
- **L4-3 姿态检查**：语气是否"有见识的普通人认真聊打动他的事"？有无滑入"导师教学生"或"品牌做营销"的姿态？
- **L4-4 心流检查**：从头到尾读有无注意力断掉的地方？需要回头理解逻辑的地方就是需要修复的节奏问题

通过标准：整体感觉"这像是真人写的"。任何"AI味太重"的段落需返工。

## 约束条件

- **排除项：** 禁止涉及政治、新闻等需资质的内容
- **兼容性：** 标题公式和情感触发必须与品类和年龄段兼容
- **多样性：** 每批选题必须覆盖不同品类和年龄段，至少1个交叉选题
- **时令/事件优先：** 有生命事件时事件优先，无事件时时令优先
- **去重审核：** 每批选题必须经过Guarder去重审核（标题公式≥3次降权，≥5次禁用）
- **交叉篇幅：** 交叉选题正文中两品类各占至少30%篇幅，禁止单品类展开+点缀
- **叙事基调伦理：** 65-80岁禁止纯焦虑，交叉选题一律赋能型
- **输出路径：** 单篇保存至 `outputs/YYYY-MM-DD-<slug>/article.md`，系列保存至 `outputs/YYYY-MM-DD-<series-slug>/series_plan.md` + 各Day的article.md
- **历史记录：** 每次创作完成后必须更新 `content_history.json`
- **风格增强必做：** 步骤7风格增强必须执行，每篇至少使用5种活人感手法
- **四层自检必做：** 步骤8四层自检必须执行，四层全部通过才算达标
- **标点禁令：** 全文禁止冒号、破折号、双引号，用逗号/「」替代
- **禁用词零容忍：** "说白了""意味着什么""本质上""换句话说""不可否认"等一律禁用

## 常见错误

| 错误 | 修正 |
|------|------|
| 全部选题来自同一品类 | 强制多样性规则 + 至少1个交叉选题 |
| 标题公式与品类不兼容 | 应用前检查适用品类约束 |
| 情感触发与年龄段不兼容 | 应用前检查适用年龄段约束 |
| 65-80岁使用纯焦虑叙事 | 切换为赋能型或温暖+赋能混合 |
| 交叉选题用焦虑基调 | 交叉选题一律赋能型 |
| 交叉选题正文只展开一个品类 | 两品类必须各占至少30%篇幅，正文含品类A方法+品类B价值+两者连接 |
| 同一标题公式高频重复 | Guarder阈值：≥3次降权，≥5次禁用 |
| 近期内容同质化 | 步骤3去重审核，高频品类/年龄段/基调/公式降权 |
| 忽略当前时令和生命事件 | 步骤1必须先读节令日历+询问事件 |
| 选题缺少推荐理由 | 每个选题必须包含推荐理由 |
| 近期内容同质化 | 步骤3去重审核，高频品类/年龄段/基调降权 |
| 未记录创作历史 | 步骤9必须追加content_history.json |
| 输出路径错误 | 严格使用 outputs/YYYY-MM-DD-slug/article.md |
| AI味过重（套话/教科书式开头） | 步骤7风格增强+步骤8四层自检，L1扫描零命中 |
| 标点使用冒号/破折号/双引号 | L1-2扫描替换，用逗号/「」替代 |
| 口语化词组不足8个 | L2-3检查，补充转场词和自嘲表达 |
| 情绪表达是知识性描述而非体感记忆 | L4-1温度感检查，改写为体感记忆式表达 |
| 节奏断裂不足3处 | L2-2检查，在情绪高点增加极短句独立成段 |
| 文化升维不自然 | L3-3检查，改为"聊着聊着自然想到了"的方式 |
