# 宝妈带娃 · 赛道定位方案

> 赛道的护城河不在关键词密度，在你比任何人更懂这个人群的隐秘痛点。

## 核心规律

赛道65%的内容停留在「共鸣宣泄」，5%停在「理性拆解」，中间的「结构化出路」极度稀缺。「宝妈」不是一个人——困顿型全职妈妈渴望收入，挣扎型职场妈妈渴望时间，痛点几乎互斥，不可用同一套内容策略服务。

## 执行路线图

### Phase 1：感受你的读者（10分钟）

不要从画像列表里"选"一个读者。先问：**你在写这篇文章时，心里浮现的是哪个具体的人？**

- 你自己就是宝妈：写你自己的困境，不用套画像名称
- 你心里有具体的朋友/粉丝/某条留言：写她
- 没有具体的人：去评论区或妈妈群读10条留言，找到一条让你心里有反应的

画像库是素材参考，不是选择菜单。同一篇文章可以混合两个画像的痛点——只要它们在你的读者身上确实同时存在。

**确认**：用1句话说出"这篇文章写给谁"——应该是具体的人或处境，不是画像类别名。

需要画像素材？读 → `references/research/01-audience-profile.md`

### Phase 2：找到你的立场（15分钟）

不是"选择一个定位方案"。是回答：**你对这个话题的真实立场是什么？**

三个定位方案提供立场参考，不是模板绑定。你可以：
- 在反鸡汤拆解派的视角下写一篇很温柔的文章
- 在黑色幽默外壳下写一篇严肃内核
- 在身份重建方法论下写一篇纯粹共鸣叙事

定位配比是长期发布节奏建议，不是单篇文章结构指令。单篇展开方式由话题性质决定。

**确认**：用1句话说出"我的立场是什么"——是你的真实态度，不是定位方案标签。

需要定位方案详情？读 → `references/research/04-differentiation.md`

### Phase 3：确定话题 + 信息密度分配（20分钟）

从痛点素材库找一个**你真正有感受的**话题点，不是"覆盖率高所以选它"。对照选题疲劳区，检查话题是否在同质化维度——如是，换角度而非换话题。

**信息密度分配**：一篇文章的重心必须不均衡。最想说的那一点给大部分篇幅，其他一点带过。关键是**不均衡**，不是"只能写一个"。

**确认**：你知道最想说的是什么，它会在文中占据最多篇幅。

需要痛点矩阵和选题方向？读 → `references/research/02-pain-point-matrix.md` 和 `references/research/03-content-directions.md`

### Phase 4：构思标题（15分钟）

标题不是因子拼接，是整体构思。好的标题从心里冒出来。

**构思原则**：
- 标题里有张力——让人想"这说的什么？"或"这怎么回事？"
- 张力可以是情绪的、认知的、身份的，或它们的自然混合
- 标题里有具体锚点——一个场景、一个数字、一个反常识判断

**反面信号**：
- 读起来像四个模块拼在一起，语义断裂
- 纯抽象概括（"全职妈妈的身体代价不容忽视"）
- 赛道高频模板词（崩溃/扎心/必看/收藏）但你选的定位不该用这些词

**确认**：标题是自然成型的想法，不是公式产物。

需要爆款模式参考？读 → `references/research/05-viral-patterns.md`

### Phase 5：写出文章（60分钟）

**从场景开始，不是从模板开始。**

1. **开头**：选定1个微场景。开头必须是感官画面，不是抽象概括。删掉开头第一句后如果意思没变，删掉。避开高频开头场景：深夜刷手机、看着孩子睡脸、一个人坐客厅。从更具体的生活动作切入
2. **骨架**：让文章跟着你的思路走。段落长度必须不均匀——最想说的写长，只想提一句的写短
3. **核心段落**：感受定位方案的参照作家的节奏和温度，然后用你自己的方式写。不是模仿作家标签，是感受质感再用自己语感表达
4. **生活质感**：冰箱嗡嗡声、奶瓶温热、孩子头发里的汗味——从你的记忆或想象自然流出，不为达标而插入
5. **结尾**：不要总结。让文章自然停——未消解的张力、突然翻转、安静画面、抛给读者的问题、斩断式断言。不要变成行动清单
6. **身份动作**：方法论型选题，身份动作融进叙事中段；共鸣型选题，不加身份动作

### 质感原则（替代规则清单）

写完后问自己三个感受问题：

1. **呼吸感**：节奏有快有慢有停顿有流动？还是每段差不多？
2. **重量感**：最想说的话占了最多篇幅？还是各点差不多重？
3. **质感**：有你真实感受的细节和声音？还是全是抽象概括？

如果三个答案都是"是"，AI味会自然很低。

### 4条硬底线

| 底线 | 为什么 |
|------|--------|
| 零破折号（——）构句 | AI最显眼指纹，中文人话写作几乎不用 |
| 无排比列举（首先/其次/最后） | AI对称模板标志 |
| 无假递进（"不是因为A，是因为B"） | 检测器核心信号，改为独立判断制造犹豫 |
| 无总结收束（综上所述/归根结底） | 总分总模板标志 |

这几条是硬底线因为它们是检测器最高权重信号。其余的——感官细节多少、自我推翻频率、个人声音出现次数——让它们从写作中自然流出，不要为达标而插入。

AI高频词底线（自然避开，不查表替换）：综上所述、首先/其次/最后、值得注意的是、在…背景下、赋能、底层逻辑、让我们探讨、革命性/颠覆式、不仅仅是——发现自己用了这些词，不是找替换词塞进去，是重新想这个点该怎么说。也许不需要这个过渡词，直接删掉。

### 作家文风参考

定位方案中的参照作家提供**质感方向**，不是写作模板。

感受余华：钝钝的、不加修饰的、像白开水但后味很重。用自己的方式写出类似感觉。

感受简媜：温温的、刻骨的、像午后阳光照在旧书页上。

感受汪曾祺：平淡白描、松弛短句、不拔高——是真的觉得这件事不需要大词来写。

感受梁实秋：克制从容。感受钱钟书：犀利刻薄。感受亦舒：清醒利落。

**关键**：感受质感→内化→用自己的方式表达。不是标签→模仿→标签组合表达。

## 框架自反性

本框架会产生以下系统性倾向，写作时应主动对抗：

- **列举倾向**：5画像27痛点6选题3定位——你的思维可能变成"从列表中选"。对抗：写作时不要默念列表，让话题从感受自然浮现
- **对称倾向**：定位方案各有立场和文风——你可能倾向在文章中也做对称展开。对抗：信息分布不均衡，7句核心+1句过渡
- **锁定倾向**：选定画像后觉得所有属性被决定。对抗：画像只决定痛点素材，文风和展开方式由真实感受决定
