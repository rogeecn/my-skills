# 职场赛道定义

## 一、目标人群是谁

职场赛道的人群不是按年龄划分，而是按**与职场的关系类型**划分——即一个人在职业生命周期中所处的阶段和面对的核心挑战。

| 关系类型 | 定义 | 核心心态 |
|----------|------|----------|
| 萌芽期（职场新人） | 0-3年职场人，刚从学校进入社会 | "我到底该怎么活？规则是什么？我能不能活下来？" |
| 上升期（成长攻坚者） | 3-8年职场人，正在争取晋升和影响力 | "我怎么才能比别人快？我的价值怎么被看见？" |
| 瓶颈期（中年困局者） | 8-15年职场人，遇到天花板或倦怠 | "我到底要不要继续？我是不是被困住了？还能不能重新开始？" |
| 转型期（破局重构者） | 主动或被迫转换赛道/角色的人 | "过去的经验还值不值钱？新的路我能不能走？" |
| 管理期（带人成事者） | 中高层管理者，核心挑战从"做事"变成"带人" | "我怎么让团队为我打仗？我的精力怎么分配？" |

**关键洞察：** 职场赛道的核心不是"技能培训"，而是**情绪共鸣+认知升级**。每一阶段的人都在寻找"有人懂我"的感觉，其次才是"有人教我"。

## 二、他们最关心什么

| 关心方向 | 具体内容 | 切入角度 |
|----------|---------|---------|
| **生存规则** | 职场潜规则、人际博弈、汇报技巧、向上管理 | 用"揭秘感"切入——把不透明规则变成可操作知识 |
| **晋升路径** | 升职逻辑、加薪策略、跳槽时机、职业规划 | 用"对标感"切入——让别人成功路径成为参照 |
| **情绪出口** | 职场焦虑、倦怠感、内耗、社交压力、996 | 用"共鸣感"切入——先承认痛苦存在，再给解法 |
| **认知升级** | 商业思维、管理思维、战略视角、行业判断 | 用"通透感"切入——把复杂现象拆成底层逻辑 |
| **身份认同** | 职业标签、专业身份、个人品牌、职业尊严 | 用"赋能感"切入——帮人定义"我是谁" |
| **生活平衡** | 工作生活平衡、副业探索、时间管理、健康 | 用"解绑感"切入——工作不是全部，你值得更多 |

## 三、品类体系

职场属于生活类赛道，设定7个品类，每品类3-5个子项：

### 品类1：职场生存（核心刚需）
- 职场潜规则与暗逻辑
- 向上管理与汇报技巧
- 人际博弈与社交策略
- 跨部门协作与资源争取
- 避坑指南与常见雷区

### 品类2：晋升加薪（高欲望）
- 升职逻辑与路径规划
- 加薪谈判与薪资策略
- 跳槽时机与选择判断
- 职业周期与阶段对标
- 能力模型与成长杠杆

### 品类3：情绪共鸣（高传播）
- 职场焦虑与倦怠
- 内耗与精神离职
- 996/加班文化反思
- 职场PUA与边界感
- "不想上班"的情绪出口

### 品类4：认知升级（高粘性）
- 商业思维与底层逻辑
- 管理思维与领导力
- 行业判断与趋势洞察
- 战略视角与全局思维
- 从执行者到决策者的转变

### 品类5：身份认同（高转化）
- 职业标签与专业身份
- 个人品牌与影响力
- 职业尊严与自我定义
- 从"打工者"到"合伙人"
- 职业转型与二次曲线

### 品类6：管理实战（高壁垒）
- 团队管理与激励
- 招人用人与辞人
- 目标管理与OKR
- 会议效率与决策机制
- 冲突处理与组织文化

### 品类7：职场生活（高共鸣）
- 工作生活平衡
- 副业与第二曲线
- 时间管理与精力分配
- 职场健康与心理韧性
- 退休规划与财务自由

### 高度兼容品类（经常一起出现）

| 组合 | 原因 |
|------|------|
| 职场生存 + 情绪共鸣 | 生存困境是情绪共鸣的触发器 |
| 晋升加薪 + 认知升级 | 升职需要认知先到位 |
| 情绪共鸣 + 身份认同 | 焦虑本质是身份迷失 |
| 管理实战 + 认知升级 | 管理是认知的外化 |
| 职场生活 + 情绪共鸣 | 生活失衡是倦怠的核心来源 |
| 晋升加薪 + 职场生存 | 活下来才能往上走 |

## 四、受众分层逻辑

职场赛道的分层逻辑是**职业阶段**，而非年龄。因为：
- 25岁的管理者面对的问题和35岁的管理者相似
- 30岁刚入行的新人和22岁的新人面对相似的困惑
- 年龄不是变量，**职业阶段**才是

| 层级 | 职业阶段标签 | 核心关键词 | 内容侧重 |
|------|-------------|-----------|---------|
| L1 | 萌芽期新人 | 生存、适应、规则 | 职场生存 + 情绪共鸣 |
| L2 | 上升期攻坚者 | 成长、竞争、价值 | 晋升加薪 + 认知升级 |
| L3 | 管理期带人者 | 管理、授权、战略 | 管理实战 + 认知升级 |
| L4 | 瓶颈/转型期 | 突围、重构、意义 | 身份认同 + 职场生活 + 情绪共鸣 |

## 五、关键适配决策预判

| # | 决策点 | 职场赛道适配值 | 理由 |
|---|--------|---------------|------|
| 1 | 受众分层方式 | 按职业阶段4档（萌芽/上升/管理/瓶颈转型） | 年龄不是变量，职业阶段才是 |
| 2 | 品类数量 | 7个 | 生活类赛道标准 |
| 3 | 品类子项数量 | 每品类5个子项 | 职场话题足够丰富 |
| 4 | 受众类型数量 | 4类 | 职业阶段4档 |
| 5 | 交叉组合数量 | 6组 | 已在品类兼容表中定义 |
| 6 | 生命事件类型 | 职业变故类15个 | 入职/晋升/离职/跳槽/倦怠等 |
| 7 | 时令锚定方式 | 通用节气节日 + 职场专项节点 | 毕业季/秋招/年终考核/晋升季 |
| 8 | 标题公式数量 | 17种 + 职场特有3种 | 增加"潜规则揭秘型""阶段对标型""职场人物型" |
| 9 | 情感触发词数量 | 5类 + 职场特有2类 | 增加"规则冲击类""身份觉醒类" |
| 10 | 风格体系名称 | "通透感" | 职场内容的核心感受是"看透了" |
| 11 | 叙事基调伦理 | 禁止贩卖焦虑 | 职场赛道最容易滑入焦虑营销 |
| 12 | 额外维度 | 职场人物档案 + 行业地图 | 职场赛道需要参照物 |
